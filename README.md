# Weather Data Aggregator (wttr.in)

Скрипт на Python для автоматического сбора данных о погоде в городах через API [wttr.in](https://wttr.in) и вычисления агрегированной статистики по странам.

## Описание решения

Скрипт выполняет следующие действия:
1. Загружает список городов из файла `cities.txt` и удаляет дубликаты.
2. Для каждого уникального города запрашивает текущую температуру и страну через API `https://wttr.in/{City}?format=j1`.
3. Сохраняет данные в модель `WeatherData` (город, температура в °C, страна) и выводит информацию по каждому городу.
4. Группирует города по странам и рассчитывает:
   - Количество городов в стране;
   - Среднюю температуру;
   - Минимальную и максимальную температуру.

### Ограничения и технологии
- **Язык:** Python 3.7+
- **Зависимости:** Только стандартная библиотека Python (`json`, `urllib.request`, `dataclasses`, `collections`). Внешние библиотеки не используются.
